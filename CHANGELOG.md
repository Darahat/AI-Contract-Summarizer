# Changelog

All notable changes to ClauseWise will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-10-23

### Added
- Initial release of ClauseWise
- Contract upload functionality (PDF, DOC, DOCX, TXT)
- AI-powered contract summarization using OpenAI/Mistral
- Risk detection for:
  - Payment terms
  - Liability clauses
  - Intellectual Property rights
- AES encryption for document security
- Local storage with Hive
- Document history management
- Free plan: 2 documents/month
- Pro plan: $12/month for unlimited documents
- Settings screen with API key configuration
- Subscription management
- Material Design 3 UI with light/dark theme support
- Riverpod state management
- Comprehensive test coverage

### Security
- AES encryption for all stored documents
- Secure API key storage
- Local-only document storage
